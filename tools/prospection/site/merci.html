Guide de démarrage

Prêt en 15 minutes

Lancez l'application

Double-cliquez sur LeadFinder.exe dans votre dossier Téléchargements. Vous pouvez le déplacer sur votre Bureau pour le retrouver facilement.

Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même. Vous ne le ferez qu'une seule fois.

Créez votre clé API Google

C'est ce qui permet à Lead Finder d'interroger Google Maps. La création est gratuite.

  1. Allez sur console.cloud.google.com et connectez-vous avec votre compte Google.
  2. Créez un nouveau projet (par exemple « prospection »).
  3. Dans Facturation, associez une carte bancaire. Google l'exige même pour le quota gratuit.
  4. Dans API et services → Bibliothèque, activez « Places API (New) » (avec « New »).
  5. Dans API et services → Identifiants, cliquez sur Créer des identifiants → Clé API et copiez la clé (elle commence par « AIza »).
Conseil : dans Facturation → Budgets et alertes, créez une alerte (par exemple 10 € par mois) pour ne jamais avoir de surprise.

Collez la clé dans Lead Finder

Au premier lancement, la fenêtre « Clé API » s'ouvre toute seule. Collez votre clé, cochez « Mémoriser sur cet ordinateur » et cliquez sur Enregistrer. En haut à droite s'affiche alors « ✔ Clé configurée ».

Lancez votre première recherche

Choisissez un métier (par exemple coiffeur), tapez une ou plusieurs villes, puis cliquez sur Rechercher. Double-cliquez un résultat pour l'ouvrir sur Google Maps, et cliquez sur Exporter Excel pour récupérer votre liste de prospects.

Si un message d'erreur apparaît, il vous indique en français quel réglage Google corriger. Dans la plupart des cas, il suffit d'attendre 2 à 3 minutes après la création de la clé.
