Getting started

Ready in 15 minutes

Launch the app

On Windows

Double-click BridgeToLeads.exe in your Downloads folder.
If Windows shows “Windows protected your PC”, click More info then Run anyway. Only once.

On Mac

  1. Double-click the downloaded .zip file to unzip it.
  2. Drag BridgeToLeads into your Applications folder, then open it.
If your Mac refuses to open it the first time, click OK, then open System Settings → Privacy & Security, scroll down and click Open Anyway. Only once.

The app opens in your computer's language. The English / Français button at the top right switches it.

Create your Google API key

This is what lets BridgeToLeads search Google Maps. Creating it is free.

  1. Go to console.cloud.google.com and sign in with your Google account.
  2. Create a new project (for example “prospecting”).
  3. In Billing, add a bank card. Google requires it even for the free quota.
  4. In APIs & Services → Library, enable “Places API (New)” (with “New”).
  5. In APIs & Services → Credentials, click Create credentials → API key and copy the key (it starts with “AIza”).
Tip: in Billing → Budgets & alerts, create an alert (for example $10 a month) so you're never surprised.

Activate your license, then paste the Google key

On first launch, the “Activate BridgeToLeads” window opens: paste the license key shown higher up on this page (it starts with “BTL-”) and click Activate (Internet connection required). It is valid on 2 computers.

Then the “API key” window opens by itself. Paste your key, tick “Remember on this computer” and click Save. “✔ Key set up” then shows at the top right.

Run your first search

Choose a trade (for example hair salon), type one or more cities (for example Austin TX), then click Search. Double-click a result to open it in Google Maps, and click Export to Excel to get your lead list.

If an error message appears, it tells you which Google setting to fix. Most of the time, you just need to wait 2 to 3 minutes after creating the key.
