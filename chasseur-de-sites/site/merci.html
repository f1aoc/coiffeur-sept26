Bienvenue dans Chasseur de sites. Votre logiciel est prêt : téléchargez-le, puis suivez les 4 étapes ci-dessous pour lancer votre première analyse.

Téléchargez Chasseur de sites

Choisissez la version de votre ordinateur. Rien à installer (environ 75 Mo).

Windows 10 / 11 Mac puce Apple M1–M4 Mac Intel

Quel Mac avez-vous ? Menu Pomme → À propos de ce Mac : « Puce Apple M… » = puce Apple, « Processeur Intel » = Intel.

Guide de démarrage

Prêt en 10 minutes

Lancez l'application

Sur Windows

Double-cliquez sur ChasseurDeSites.exe dans votre dossier Téléchargements.
Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même. Une seule fois.

Sur Mac

  1. Double-cliquez sur le fichier .zip téléchargé pour le décompresser.
  2. Glissez ChasseurDeSites dans votre dossier Applications, puis ouvrez-le.
Si le Mac refuse de l'ouvrir la première fois, cliquez sur OK, puis ouvrez Réglages Système → Confidentialité et sécurité, descendez et cliquez sur Ouvrir quand même. Une seule fois.

Une petite fenêtre « Chasseur de sites » s'ouvre. La première fois, elle télécharge le navigateur d'analyse (environ 150 Mo, quelques minutes), puis l'application s'ouvre toute seule dans votre navigateur internet.

Gardez la petite fenêtre ouverte (vous pouvez la réduire) : la fermer arrête l'application.

Activez votre licence, puis présentez votre agence

L'application vous demande votre clé de licence : c'est celle affichée plus haut sur cette page (elle commence par « CDS- »). Collez-la puis cliquez sur Activer (connexion à Internet nécessaire). Elle est valable sur 2 ordinateurs.

Ensuite, dans Réglages → Votre agence, indiquez votre nom, votre logo, votre couleur et vos coordonnées. Ils apparaîtront sur vos rapports PDF et dans vos messages.

Trouvez des entreprises

Sans clé Google : dans Nouvelle analyse, glissez un fichier CSV ou Excel avec au moins le nom et l'adresse du site de chaque entreprise.

Avec la recherche « métier + ville » : il faut une clé Google Maps (création gratuite).

  1. Allez sur console.cloud.google.com et connectez-vous avec votre compte Google.
  2. Créez un nouveau projet (par exemple « prospection »).
  3. Dans Facturation, associez une carte bancaire. Google l'exige même pour le quota gratuit.
  4. Dans API et services → Bibliothèque, activez « Places API (New) » (avec « New »).
  5. Dans API et services → Identifiants, cliquez sur Créer des identifiants → Clé API et copiez la clé (elle commence par « AIza »).
  6. Collez-la dans Réglages → Clés API de Chasseur de sites.
Conseil : dans Facturation → Budgets et alertes, créez une alerte (par exemple 10 € par mois). Chasseur de sites affiche aussi une estimation du coût avant chaque recherche.

Lancez votre première analyse

Dans Recherche, tapez un métier (par exemple coiffeur) et vos villes, cliquez sur Lancer la recherche puis sur Lancer l'analyse. Suivez l'avancement, puis ouvrez les Résultats : les sites les plus mal en point sont en haut.

Cliquez sur le nom d'une entreprise pour voir ses captures, générer son rapport PDF et copier l'e-mail, le script d'appel ou le SMS déjà rédigés.

Cochez « Prospects prioritaires » pour ne garder que les sites en panne ou dépassés d'entreprises bien notées sur Google : ce sont vos meilleurs appels.
